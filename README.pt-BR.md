[![CI](https://github.com/FelipeMadson/agentic-consensus-workflow-engine/actions/workflows/ci.yml/badge.svg)](https://github.com/FelipeMadson/agentic-consensus-workflow-engine/actions)

Motor de fluxo de trabalho agêntico e consenso multi-agente determinístico desenvolvido por [Felipe Madison](https://github.com/FelipeMadson). Implementa avaliação de quórum ponderado, pontuação de confiança e validação de contratos Zod em tempo de execução.

## Compilação e Testes

```bash
npm install
npm run build
npm test
```
